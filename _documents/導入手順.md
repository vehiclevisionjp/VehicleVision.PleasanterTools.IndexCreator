# 導入手順

本書は IndexCreator を配置・設定する運用管理者向けです。日常のコマンドは [利用ガイド](利用ガイド.md)、更新時の操作は [運用手順](運用手順.md) を参照してください。

## 必要な環境

- Windows x86 / x64、Linux x64 または Linux arm64。
- [.NET Runtime 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)。SDK は不要です。
- 稼働中の Pleasanter と、その DB のインデックス管理権限を持つ接続設定。

対象の Pleasanter 版で代表ビューと登録・更新の動作を確認してから運用してください。

## ファイルを配置する

[Release ページ](https://github.com/vehiclevisionjp/VehicleVision.PleasanterTools.IndexCreator/releases) の Assets から OS に合う `IndexCreator-<RID>.zip` と同名の `.zip.sha256` を取得します。Source code の ZIP はソースの配布です。

| 実行環境 | 配布 ZIP |
| --- | --- |
| Windows x86 | IndexCreator-win-x86.zip |
| Windows x64 | IndexCreator-win-x64.zip |
| Linux x64 | IndexCreator-linux-x64.zip |
| Linux arm64 | IndexCreator-linux-arm64.zip |

SHA256 を確認して展開し、`IndexCreator` フォルダを本体・CodeDefiner と同階層へ置きます。

**Azure App Service の Windows 版 Kudu で実行する場合は、x86 版（`IndexCreator-win-x86.zip`）を使ってください。** 詳しくは [App Service への配置](AppService導入手順.md) を参照してください。

Windows では、本体の実行に使う `dotnet --info` の Host Architecture に合わせて選びます。`x86` なら win-x86、`x64` なら win-x64 です。64bit Windows 上でも、起動する `dotnet` が x86 の場合は win-x86 を使ってください。ランタイムも配布物と同じアーキテクチャの .NET 10 が必要です。v0.1.0 の配布物には Windows x86 版が含まれていません。

```text
pleasanter/
├── Implem.Pleasanter/
│   └── App_Data/Parameters/
├── Implem.CodeDefiner/
└── IndexCreator/
    ├── IndexCreator.dll
    ├── LICENSE
    └── NOTICE
```

## 接続設定を確認する

本体の `Rds.json` の `Dbms` と `OwnerConnectionString`、`Service.json` の `Name` を読みます。`#ServiceName#` はサービス名に置換します。`Env.json` の `ParametersPath` が設定されている場合は、そのフォルダから本体の設定を読みます。

**`DisableIndexChangeDetection` を `true` にしてください。** 未設定・false では適用を停止します。本アプリは設定ファイルを変更しません。SaConnectionString は使用しません。

SQL Server は dbo、PostgreSQL・MySQL は Service.Name が既定のスキーマです。異なる場合は `/schema` で指定します。資格情報をコマンドラインへ書かないでください。

環境変数で設定する場合、接続文字列は次の最初の空でない値です。

1. `INDEXCREATOR_CONNECTION_STRING`
2. Rds.json の `OwnerConnectionString`
3. Service.EnvironmentName + `_OwnerConnectionString`
4. Service.Name + `_Rds_<Dbms>_OwnerConnectionString`
5. Service.Name + `_Rds_<Dbms>_ConnectionString`
6. Service.Name + `_Rds_OwnerConnectionString`
7. Service.Name + `_Rds_ConnectionString`

DBMS は `/dbms` → `INDEXCREATOR_DBMS` → Rds.json の順、スキーマは `/schema` → `INDEXCREATOR_SCHEMA` → 既定値の順です。タイムアウトは Rds.json の SqlCommandTimeOut に従います。0 は無期限です。

## 初回の実行

`IndexCreator` フォルダで次を実行します。

```powershell
dotnet IndexCreator.dll help
dotnet IndexCreator.dll plan
```

配置を自動で解決できない場合は CodeDefiner と同じ `/p` で本体フォルダを指定します。

```powershell
dotnet IndexCreator.dll plan /p "C:\web\pleasanter\Implem.Pleasanter"
dotnet IndexCreator.dll plan /p /opt/pleasanter/Implem.Pleasanter
```

TLS 証明書を検証する接続設定を使います。本アプリは証明書検証を自動で無効化しません。接続失敗時は資格情報、証明書名・信頼、DB の権限を確認してください。DB 例外詳細と接続文字列はコンソールに表示しません。

候補の列と実行計画、値の最大長を確認し、必要な候補だけを採用できるサイト設計か判断してから `apply` を実行します。初版には候補ごとの選択機能がないため、サイト構成に由来する候補全体を適用します。
